# 单独持久化不含正文的 Audit Record

与安全相关的 Bridge 操作会生成持久 Audit Record，并与 Operational Log 和 Message Archive Content 分离，覆盖 Administration、Role 与 Access Policy 变更、Channel 与 Thread Binding 变更、Approval Transport Outcome、Backup 或 Restore、Purge 和手动 Circuit-breaker 操作。每条记录仅包含内部 Actor 与 Target Reference、Action、Result、Time 和 Correlation Identity，绝不包含 Message 或 Command Body、Secret 或原始 Provider Identity；相关 Message Archive Content 被清除后记录仍保留。System Administrator 可以通过已授权的主机本地 OS Identity 查询系统级和所有 Profile 记录，Profile Administrator 仅能查询自己的 Profile；Participant 和 Channel Command 无权访问。Export 需要显式 Destination、Allowlisted Schema 和 Owner-only Permission。Audit Record 默认无限期保留；只有 System Administrator 可以配置或执行 Retention，且删除前必须预览准确时间范围和记录数量并显式确认。每次清理都会追加一条豁免清理、永久保留且不含正文的 Audit Record，记录 Actor、删除范围、记录数量和摘要；Message Archive Purge 绝不触发 Audit Cleanup。首版不宣称存储具备 Tamper-proof 能力。
