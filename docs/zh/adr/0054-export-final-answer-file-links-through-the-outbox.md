# ADR 0054：通过 Outbox 导出最终回复中的文件链接

状态：通过 macOS 真实验收后纳入 `0.2.0-rc.1`；其他目标平台仍待验收。

Codex 拥有文件生成与权威已完成 `agentMessage.text`；文件修改事件不是附件清单。
Bridge 拥有外部文件投递。用户选择自动交付，不采用 `/file` 命令。

Profile 显式启用后，对已完成最终回复中的工作区本地 Markdown 链接进行有界识别。
不扫描工作区、不从工具输出推断附件，不建立竞争性的 Codex 产物/历史模型。
先对合法字节创建快照，再在现有终态 Logical Result 事务中同时提交文字和附件元数据。
Schema 11 为 Outbox 增加可空文件元数据，保留旧文字结果摘要。迁移仍须经过现有
显式快照/确认门槛。

启用即允许向原会话（包括其群成员）导出工作区文件，不代表内容分类或恶意进程隔离。
平台上传、消息发送与收件下载是不同事实，保留回执、重试与可能重复窗口。
参见[操作说明](../output-files.md)。
