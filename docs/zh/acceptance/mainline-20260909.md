## 部署生命周期

- macOS launchd 与 Linux systemd 用户服务均通过预览、错误确认拒绝、安装不自动
  启动、重复注册拒绝、启动、重启、原生默认值查询、停止、卸载；确认 Supervisor
  退出，配置与 SQLite 状态保留。
- 配置文件名包含空格、美元符号和百分号，两个后端均保留了字面路径。
- Linux 首次正确拒绝组可写的用户 unit 目录（0775）。操作者核对所有权后，仅
  移除该目录的组写权限（0755），未递归改动；重试通过。这是环境修正，不是绕过
  安全检查或修改运行时代码。
- Docker 通过引擎报告的 healthy 状态、Supervisor/Profile 就绪、原生默认值查询、
  配置应用、重启和无 OOM 的零退出码停止。测试容器已移除，挂载数据保留。
