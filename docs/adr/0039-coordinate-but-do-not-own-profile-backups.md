# Coordinate but do not own Profile backups

The Bridge will provide host-local backup prepare and finish coordination for a named Profile, but it will not create a proprietary full-backup package: prepare drains the Profile, checkpoints Bridge SQLite, flushes the outbox, stops the worker and App Server, and emits a versioned verification manifest. The administrator's existing backup tooling snapshots the listed Bridge-owned data, complete Codex home, optional Workspace, and separately managed credential material; the Bridge does not copy, parse, convert, or repackage Codex history or Workspace files. Restore places those files back while stopped and must pass Bridge validation before the worker starts; the first release does not promise a live consistent backup across all ownership domains.
