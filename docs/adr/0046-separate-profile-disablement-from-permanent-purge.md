# Separate Profile disablement from permanent purge

Removing or disabling a Profile in configuration will bounded-drain and stop its worker while retaining its data, Channel authentication, and Channel Bindings for later recovery; no configuration reload may implicitly delete or reassign them. Permanent purge is a separate host-local command available only after the Profile is disabled with no live work—no active Turn, queued input, pending Approval Request, pending user-input request, or pending outbox delivery—and requires a preview of counts and exact Bridge-owned paths plus confirmation using the full Profile ID. Purge deletes only Bridge-owned state, Message Archive, media, and local Channel authentication, preserves and reports the Workspace and Codex home without modifying Codex internals, and leaves a body-free Profile Tombstone and Audit Record because a purged Profile ID is never reused.
