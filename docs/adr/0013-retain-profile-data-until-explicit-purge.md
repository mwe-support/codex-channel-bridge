# Retain Profile data until explicit purge

Disabling or ordinarily deleting a Profile retains its recoverable Message Archive and delivery state, so “permanent” means retained until a deliberate host-local administrator action rather than undeletable. Profile purge and Archive Purge remain distinct, and no Channel command or automatic retention policy may delete archive content; the first release limits Archive Purge to either one Profile's whole archive or records in one exact Channel Conversation older than a specified time, after previewing scope, counts, media bytes, and live references and confirming with the Profile ID and expected count. Any active Turn, queue, approval, or outbox reference rejects the whole operation; otherwise base rows and FTS entries are deleted transactionally, only unreferenced content-addressed media is reclaimed, Bindings and Codex history remain untouched, and a body-free Audit Record captures the scope, count, and deleted-set digest.
