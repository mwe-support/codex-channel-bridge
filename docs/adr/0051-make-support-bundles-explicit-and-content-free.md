# Make Support Bundles explicit and content-free

`bridge doctor` remains read-only, and a Support Bundle is created only by an authorized host-local administrator after previewing its Profiles, time range, allowlisted fields, size, and explicit owner-only output path. The bundle contains only version, schema, capability, reason-code, state-transition, count, duration, migration, SQLite-integrity, and redacted configuration-shape metadata plus a manifest and file digests; it never includes Channel or Codex content, reasoning, Codex home, Workspace contents, media, authentication, Secret Reference names or values, pairing material, raw provider identities, signed URLs, or complete local paths, and the first release provides no content override. The Bridge audits creation without content, never uploads a bundle, configures no vendor endpoint, and makes no tamper-resistance claim.
