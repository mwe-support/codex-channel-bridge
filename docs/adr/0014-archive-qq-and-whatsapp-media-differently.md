# Archive QQ and WhatsApp media differently

QQ media will default to permanent metadata and provider-link records with optional immediate mirroring, acknowledging that a retained link does not guarantee future byte recovery. Baileys-delivered WhatsApp media will be streamed into SHA-256 content-addressed storage as soon as decrypted bytes are observable because its temporary plaintext path cannot serve as a durable source. Mirroring defaults to a 64 MiB per-attachment limit and a 10 GiB per-Profile soft quota, both locally configurable; exceeding a limit retains metadata with an explicit bytes-unavailable state. Restore and mirroring enforce bounded streaming, redirects and URL safety, original filenames never determine storage paths, and attachments are never executed automatically. A deployment may require an external scanning hook before Codex can read mirrored bytes.
