# Distinguish disconnection from authentication revocation

`disconnect` is reversible and stops only an adapter while preserving its binding and authentication, whereas `logout` or `revoke` is a destructive, Profile-administrator action allowed only after the account is drained with no active Turn, pending Approval Request, or outbox delivery. WhatsApp local Baileys state is deleted only after confirmed provider logout; an uncertain result stops reconnect with reason `auth_revoke_uncertain` until retry or an explicitly warned `forget-local`, which cannot prove remote invalidation. QQ supports disconnect but delegates developer-credential revocation or rotation to Tencent's official console and a subsequent System Administrator Secret Reference update. These operations preserve archive, media, bindings, Codex Threads, and Workspace data, and Audit Records contain only internal references, result, and remote-confirmation status.
