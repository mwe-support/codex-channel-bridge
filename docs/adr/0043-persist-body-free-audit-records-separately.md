# Persist body-free Audit Records separately

Security-relevant Bridge actions will create durable Audit Records distinct from operational logs and Message Archive content, covering administration, roles and Access Policies, Channel and Thread Bindings, approval transport outcomes, backup or restore, purge, and manual circuit-breaker operations. Each record contains only internal actor and target references, action, result, time, and correlation identity—never message or command bodies, secrets, or raw provider identities—and remains after related Message Archive content is purged. A System Administrator may query system-wide and all Profile records through an authorized host-local OS identity, while a Profile Administrator is limited to its Profile; Participants and Channel commands have no access. Export requires an explicit destination, an allowlisted schema, and owner-only permissions. Audit Records are retained indefinitely by default; only a System Administrator may configure or execute retention, after previewing the exact time range and record count and explicitly confirming deletion. Each cleanup appends an exempt, permanently retained, body-free Audit Record containing the actor, deleted range, record count, and digest, and Message Archive purge never triggers audit cleanup. The first release does not claim tamper-proof storage.
