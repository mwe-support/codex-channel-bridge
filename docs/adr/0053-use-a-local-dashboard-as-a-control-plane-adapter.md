# Use a local Dashboard as a control-plane adapter

This supersedes only ADR 0041's Web Console deferral; host-local IPC remains authoritative. The first usability release may provide an optional `bridge dashboard` command that starts a loopback-only HTTP server and prints an unguessable, launch-scoped browser URL to the initiating terminal. The Dashboard is an adapter over the existing host-local control-plane interface: it may display deployment and Profile health, Channel connectivity, bounded content-free operational events, and the redacted configuration shape, but it must not access a Worker, Profile database, Message Archive, Codex home, or Workspace directly. Configuration changes reuse the existing plan, redacted diff, explicit confirmation, authorization, restart, and Audit Record contracts. Closing the Dashboard invalidates its browser capability. LAN, public, unattended, or multi-user access is outside this decision and requires a later ADR defining TLS and administrator identity.
