# Connect channels directly to Codex App Server

The project will be an independent Codex Channel Bridge whose own channel adapters connect Channel Conversations directly to Codex App Server. Existing Hermes QQ, WhatsApp, and Codex plugins are research material only: Hermes, OpenClaw, and other general agent gateways will not be runtime dependencies, because the Bridge must own Channel routing, durable delivery, and transport of native Codex lifecycle and approvals rather than inherit another gateway's session model. Independence includes repository lineage: the new `main` history retains no Hermes commits, branches, tags, remotes, CI, deployment assets, plugin code, or operational documents, and begins from this project's authoritative design, research, license, and newly written project files. Any later reuse of legacy source requires a file-level license review and NOTICE attribution rather than assuming that presence in the exploratory worktree grants permission.
