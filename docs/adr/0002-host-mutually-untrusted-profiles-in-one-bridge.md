# Host mutually untrusted Profiles in one Bridge

One Codex Channel Bridge deployment will host multiple Profiles for mutually untrusted users or departments, following the useful isolation shape of one Hermes Gateway with multiple profiles without retaining Hermes as a dependency. Each Profile owns distinct QQ and WhatsApp Channel Bindings and is an application-level security boundary rather than a display label; the selected shared-OS-user process model does not by itself provide hostile-process isolation.
